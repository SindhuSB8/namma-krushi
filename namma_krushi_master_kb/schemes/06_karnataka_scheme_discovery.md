# Karnataka scheme discovery

For Karnataka farmers, use official state portals alongside national schemes. Raita Mitra and the Karnataka Department of Horticulture publish agriculture/horticulture services, schemes and department information. myScheme is a national discovery platform that can filter schemes based on eligibility information.

## Chatbot behavior

If a farmer asks a broad question such as “Which government scheme can help me build a polyhouse?”, first identify the need (protected structure, irrigation, crop insurance, credit, post-harvest infrastructure). Then return the most relevant official scheme category and link.

If the user asks “Am I eligible?”, do not guess from incomplete information. Ask only the minimum relevant factors and still advise checking the current official notification/application portal.

Scheme content should be re-verified periodically because benefit patterns, application windows and implementing departments change.
