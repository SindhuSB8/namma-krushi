# Namma Krushi

**An AI-Driven Kannada-English Advisory System for Greenhouse Tomato Cultivation**

## Project Overview

Namma Krushi is an AI-powered agricultural advisory system designed to support greenhouse tomato farmers through intelligent disease detection, greenhouse environment analysis, and AI-based farming recommendations.

## Key Features

- **Tomato Disease Detection:** Identifies tomato leaf diseases using deep learning.
- **Greenhouse Analysis:** Evaluates temperature, humidity, soil moisture, light intensity, and CO2 levels.
- **AI Farming Assistant:** Provides agricultural guidance in Kannada and English.
- **Government Schemes:** Helps farmers explore relevant agricultural schemes and benefits.
- **History & Reports:** Maintains previous predictions, greenhouse analyses, and advisory records.

## Technologies Used

- Python
- Deep Learning / CNN
- Streamlit
- SQLite
- Natural Language Processing
- Retrieval-Augmented Generation (RAG)

## How to Run

1. Clone the repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `python -m streamlit run app.py`
